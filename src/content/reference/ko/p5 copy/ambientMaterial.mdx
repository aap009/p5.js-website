  <p>Sets the ambient color of shapes’ surface material.</p>

  <p>The <code>ambientMaterial()</code> color sets the components of the

  <a href="/reference/p5/ambientLight/">ambientLight()</a> color that shapes will

  reflect. For example, calling <code>ambientMaterial(255, 255, 0)</code> would cause a

  shape to reflect red and green light, but not blue light.</p>

  <p><code>ambientMaterial()</code> can be called three ways with different parameters to

  set the material’s color.</p>

  <p>The first way to call <code>ambientMaterial()</code> has one parameter, <code>gray</code>.

  Grayscale values between 0 and 255, as in <code>ambientMaterial(50)</code>, can be

  passed to set the material’s color. Higher grayscale values make shapes

  appear brighter.</p>

  <p>The second way to call <code>ambientMaterial()</code> has one parameter, <code>color</code>. A

  <a href="/reference/p5/p5.Color">p5.Color</a> object, an array of color values, or a

  CSS color string, as in <code>ambientMaterial('magenta')</code>, can be passed to set

  the material’s color.</p>

  <p>The third way to call <code>ambientMaterial()</code> has three parameters, <code>v1</code>,
  <code>v2</code>,

  and <code>v3</code>. RGB, HSB, or HSL values, as in <code>ambientMaterial(255, 0, 0)</code>, can

  be passed to set the material’s colors. Color values will be interpreted

  using the current <a href="/reference/p5/colorMode/">colorMode()</a>.</p>

  <p>Note: <code>ambientMaterial()</code> can only be used in WebGL mode.</p>
