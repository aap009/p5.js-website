description: >
  <p>Applies a transformation matrix to the coordinate system.</p>

  <p>Transformations such as

  <a href="/reference/p5/translate/">translate()</a>,

  <a href="/reference/p5/rotate/">rotate()</a>, and

  <a href="/reference/p5/scale/">scale()</a>

  use matrix-vector multiplication behind the scenes. A table of numbers,

  called a matrix, encodes each transformation. The values in the matrix

  then multiply each point on the canvas, which is represented by a vector.</p>

  <p><code>applyMatrix()</code> allows for many transformations to be applied at once. See

  <a href="https://en.wikipedia.org/wiki/Transformation_matrix/" target="_blank">Wikipedia</a>

  and <a href="https://developer.mozilla.org/en-US/docs/Web/API/WebGL_API/Matrix_math_for_the_web/"
  target="_blank">MDN</a>

  for more details about transformations.</p>

  <p>There are two ways to call <code>applyMatrix()</code> in two and three dimensions.</p>

  <p>In 2D mode, the parameters <code>a</code>, <code>b</code>, <code>c</code>, <code>d</code>,
  <code>e</code>, and <code>f</code>, correspond to

  elements in the following transformation matrix:</p>

  <blockquote>

  <p><img style="max-width: 150px" src="/assets/transformation-matrix.png" alt="The transformation
  matrix used when applyMatrix is called in 2D mode."/></p>

  </blockquote>

  <p>The numbers can be passed individually, as in

  <code>applyMatrix(2, 0, 0, 0, 2, 0)</code>. They can also be passed in an array, as in

  <code>applyMatrix([2, 0, 0, 0, 2, 0])</code>.</p>

  <p>In 3D mode, the parameters <code>a</code>, <code>b</code>, <code>c</code>, <code>d</code>,
  <code>e</code>, <code>f</code>, <code>g</code>, <code>h</code>, <code>i</code>,

  <code>j</code>, <code>k</code>, <code>l</code>, <code>m</code>, <code>n</code>, <code>o</code>,
  and <code>p</code> correspond to elements in the

  following transformation matrix:</p>

  <p><img style="max-width: 300px" src="/assets/transformation-matrix-4-4.png" alt="The
  transformation matrix used when applyMatrix is called in 3D mode."/></p>

  <p>The numbers can be passed individually, as in

  <code>applyMatrix(2, 0, 0, 0, 0, 2, 0, 0, 0, 0, 2, 0, 0, 0, 0, 1)</code>. They can

  also be passed in an array, as in

  <code>applyMatrix([2, 0, 0, 0, 0, 2, 0, 0, 0, 0, 2, 0, 0, 0, 0, 1])</code>.</p>

  <p>By default, transformations accumulate. The

  <a href="/reference/p5/push/">push()</a> and <a href="/reference/p5/pop/">pop()</a> functions

  can be used to isolate transformations within distinct drawing groups.</p>

  <p>Note: Transformations are reset at the beginning of the draw loop. Calling

  <code>applyMatrix()</code> inside the <a href="/reference/p5/draw/">draw()</a> function won't

  cause shapes to transform continuously.</p>
