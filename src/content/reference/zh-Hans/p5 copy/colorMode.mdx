description: |
  <p>Changes the way color values are interpreted.</p>
  <p>By default, the <code>Number</code> parameters for <a href="/reference/p5/fill/">fill()</a>,
  <a href="/reference/p5/stroke/">stroke()</a>,
  <a href="/reference/p5/background/">background()</a>, and
  <a href="/reference/p5/color/">color()</a> are defined by values between 0 and 255
  using the RGB color model. This is equivalent to calling
  <code>colorMode(RGB, 255)</code>. Pure red is <code>color(255, 0, 0)</code> in this model.</p>
  <p>Calling <code>colorMode(RGB, 100)</code> sets colors to use RGB color values
  between 0 and 100. Pure red is <code>color(100, 0, 0)</code> in this model.</p>
  <p>Calling <code>colorMode(HSB)</code> or <code>colorMode(HSL)</code> changes to HSB or HSL system
  instead of RGB. Pure red is <code>color(0, 100, 100)</code> in HSB and
  <code>color(0, 100, 50)</code> in HSL.</p>
  <p><a href="/reference/p5/p5.Color">p5.Color</a> objects remember the mode that they were
  created in. Changing modes doesn't affect their appearance.</p>
