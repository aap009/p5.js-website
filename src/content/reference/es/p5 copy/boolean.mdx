  <p>Converts a <code>String</code> or <code>Number</code> to a <code>Boolean</code>.</p>

  <p><code>boolean()</code> converts values to <code>true</code> or <code>false</code>.</p>

  <p>The parameter, <code>n</code>, is the value to convert. If <code>n</code> is a string, then

  <code>boolean('true')</code> will return <code>true</code> and every other string value will

  return <code>false</code>. If <code>n</code> is a number, then <code>boolean(0)</code> will return
  <code>false</code>

  and every other numeric value will return <code>true</code>. If an array is passed, as

  <code>in boolean([0, 1, 'true', 'blue'])</code>, then an array of Boolean values will

  be returned.</p>
